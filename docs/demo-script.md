# Demo video script (2–4 min) — outline

1. **Hook (0:00–0:20).** "Your money is on Bitcoin, Base, Tron. The app you want is on Solana. Today that means a
   bridge, gas on two chains, and a prayer." Show the Aurora Deposit home screen on a phone.
2. **Connect (0:20–0:40).** Tap *Select Wallet* → Phantom. Point at live SOL/USDC balance read from Solana.
3. **Permanent address (0:40–1:30).** Receive USDC → Permanent address → Ethereum & EVM → address + QR.
   "Same address on every EVM chain, forever." Send a few dollars from a Base wallet / exchange. Cut to Activity:
   received → delivered, Solscan link, balance updates.
4. **One-time swap with refunds (1:30–2:30).** Bitcoin → BTC → amount → refund address → quote with guaranteed
   minimum → deposit address → status stepper (PENDING → PROCESSING → SUCCESS). Mention REFUNDED path.
5. **How it works (2:30–3:15).** Architecture slide: Wallet Adapter → our proxy → Aurora Intents (1Click +
   Intents Deposits) → NEAR Intents solvers → Solana mainnet. Non-custodial, open source, MIT.
6. **Close (3:15–3:40).** "Any chain in, Solana out. One address." Live URL + repo URL on screen.

Recording notes: use real mainnet with tiny amounts; pre-fund a Base wallet; keep a completed swap's deposit
address handy in case live settlement is slow on camera.
